# Superlog Helm Charts

Public Helm charts maintained by Superlog.

## Porter

The [`superlog-otel`](charts/superlog-otel) chart provides a one-add-on install
for Kubernetes logs, metrics, events, and application OpenTelemetry signals.

Use this repository URL in Porter's **Helm Repository URL** field:

```text
https://superloglabs.github.io/helm-charts
```

The complete UI-only installation guide is in the
[`superlog-otel` chart README](charts/superlog-otel/README.md).
